# API-Sentinel: Runtime BOLA & Shadow API Detection Engine
## Week 3 Deliverable — Python Traffic Parser Integration, FastAPI Gateway & Live SOC Dashboard

---

### 1. Project Introduction
**API-Sentinel** is an API cybersecurity monitoring engine designed to protect modern cloud backends from unauthorized resource access and visibility blind spots. The core engine focuses on two critical OWASP API Security Top 10 categories:
- **Shadow API Discovery:** Identifying active endpoints exposed in network traffic that are absent from formal OpenAPI/Swagger specifications.
- **Runtime BOLA Detection:** Flagging Broken Object Level Authorization attempts where authenticated users manipulate path or query IDs to access data belonging to other tenants or users.

### 7. Commands to Start Backend & Frontend

#### Terminal 1 — Start FastAPI Backend Service (Port 8000):
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
*API Gateway accessible at: `http://127.0.0.1:8000` (Interactive docs at `http://127.0.0.1:8000/docs`)*

#### Terminal 2 — Start React SOC Dashboard (Port 3000):
```bash
npm run dev
```
*Dashboard accessible at: `http://127.0.0.1:3000`*

#### Run Automated Test Suites:
- **Run Python Backend & Parser Tests (15 tests):**
  ```bash
  python backend/test_backend.py
  ```
- **Run Frontend Integration Test Suite (49 assertions):**
  ```bash
  node scripts/test-suite.js
  ```
- **Run Traffic Parser Directly:**
  ```bash
  python parser/traffic_parser.py
  ```
- **Generate Event Summary Report:**
  ```bash
  python parser/event_summary.py
  ```
- **Create & Preview Production Build:**
  ```bash
  npm run build
  npm run preview
  ```

### 8. Dashboard Features & Integration

| Feature | Description |
| :--- | :--- |
| **Full-Stack Telemetry Flow** | `sample_events.json` &rarr; `traffic_parser.py` &rarr; `logs/parsed_events.json` &rarr; FastAPI Gateway &rarr; React Dashboard. |
| **FastAPI REST Gateway** | Dedicated `/api/v1/` endpoints with safe subprocess runner, CORS, and health checks. |
| **In-App "Run Parser"** | Header-level and banner action allowing analysts to trigger parser re-runs with instant feedback. |
| **Data Mode Switcher** | Seamlessly toggle between `DEMO MODE` (1,284 mock requests) and `BACKEND API` (4 live parsed transactions). |
| **No Silent Fallbacks** | If the backend goes offline, surfaces an informative connection-refused banner with retry controls. |
| **BOLA Ethical Triage** | Mismatched user/owner IDs (`user_2` / `user_1`) are labeled as **Potential Authorization Review Candidates**, not confirmed exploits. |
| **Shadow API Classification** | 404 uncataloged routes are marked as **Uncataloged Route Observations**, requiring verification against API catalog. |
| **Deep SOC Event Inspector** | Modal view with detection heuristics, remediation advice, sanitized headers, and masked-by-default JSON payloads. |
| **Multi-Criteria Filtering** | Instant search and filtering across method, documentation status, risk, severity, client IP, and status code. |
